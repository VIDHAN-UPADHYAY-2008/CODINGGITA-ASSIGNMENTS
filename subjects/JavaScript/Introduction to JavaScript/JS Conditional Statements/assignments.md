# JavaScript Assignment: Conditional Statements

---

## A] if Statement

### 1. Check if a number is divisible by 5

```javascript
let num = 25;

if (num % 5 == 0) {
    console.log("Divisible by 5");
}
```

### 2. Check Senior Citizen

```javascript
let age = 65;

if (age >= 60) {
    console.log("Senior Citizen");
}
```

### 3. Check Big Number

```javascript
let num = 150;

if (num > 100) {
    console.log("Big Number");
}
```

### 4. Check Temperature

```javascript
let temperature = 5;

if (temperature < 10) {
    console.log("Very Cold");
}
```

### 5. Check Perfect Score

```javascript
let marks = 100;

if (marks == 100) {
    console.log("Perfect Score");
}
```

### 6. Check Negative Number

```javascript
let num = -5;

if (num < 0) {
    console.log("Negative Number");
}
```

### 7. Check Empty String

```javascript
let input = "";

if (input == "") {
    console.log("No input provided");
}
```

### 8. Check Century Year

```javascript
let year = 1900;

if (year % 100 == 0) {
    console.log("Century Year");
}
```

### 9. Check Positive Even Number

```javascript
let num = 8;

if (num > 0 && num % 2 == 0) {
    console.log("Positive Even Number");
}
```

### 10. Check Valid Marks

```javascript
let marks = 75;

if (marks >= 35 && marks <= 100) {
    console.log("Valid Marks");
}
```
